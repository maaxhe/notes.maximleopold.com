Was ist ein CNN?

Convolutional Neural Network – „faltendes neuronales Netz"

Ein CNN ist eine spezielle Form eines künstlichen neuronalen Netzes, das räumliche Muster in Bildern (oder Audio, Video, Zeitreihen) erkennt.

Statt jeden Pixel einzeln zu betrachten, schaut ein CNN durch kleine Fenster über das Bild und sucht nach wiederkehrenden Mustern – Kanten, Ecken, Texturen, später Augen, Räder, Buchstaben.

Erfunden von ...

Yann LeCun, Ende der 1980er. Sein Netz LeNet-5 erkannte handgeschriebene Postleitzahlen.

Durchbruch

AlexNet (2012) gewann den ImageNet-Wettbewerb mit großem Abstand und löste den Deep-Learning-Boom aus.

Wo begegnen uns CNNs heute?

📱 Smartphone

Gesichtserkennung beim Entsperren, Foto-Verbesserung, Bokeh-Effekt, Objekterkennung in Fotos.

🚗 Autonomes Fahren

Erkennung von Verkehrsschildern, Fußgängern, Fahrbahnmarkierungen.

🏥 Medizin

Auswertung von Röntgen-, MRT- und CT-Bildern, Erkennung von Tumoren oder diabetischer Retinopathie.

🌾 Landwirtschaft

Drohnenbilder analysieren, Schädlinge oder Krankheiten an Pflanzen erkennen.

🛰️ Satellitenbilder

Waldbrände, Abholzung, Stadtentwicklung – automatisiert ausgewertet.

🎨 Kreative KI

CNNs sind Bausteine in Bildgeneratoren wie Stable Diffusion (im Encoder/Decoder).

Wie „sieht" ein Computer ein Bild?

Ein Bild ist für den Rechner einfach eine Tabelle aus Zahlen.

Jedes Pixel hat einen Helligkeitswert (Graustufe: 0–255).
Bei Farbbildern gibt es drei solcher Tabellen: R, G, B.

Aus Sicht des Netzes: nur eine Matrix von Zahlen – keine „Augen", keine Vorstellung von Form. Das CNN muss die Bedeutung erst lernen.

→ Eine 224×224-Farbeingabe = 150.528 Zahlen.

Beispiel: stilisierte „7" als 8×8-Pixelmatrix

Warum reicht ein klassisches Netz nicht?

Problem 1: Zu viele Parameter

Verbindet man jedes Pixel eines 224×224×3-Bildes mit nur 1.000 Neuronen, erhält man bereits ~150 Mio. Gewichte – pro Schicht.

Problem 2: Keine Translationsinvarianz

Verschiebt man eine Katze um 5 Pixel nach rechts, „sieht" das klassische Netz ein völlig anderes Bild.

Problem 3: Räumliche Struktur geht verloren

Pixel werden zu einem langen Vektor „flachgeklopft" – Nachbarschaften zählen plötzlich nicht mehr.

💡 Die Lösung des CNN

Gewichte teilen. Statt jedes Pixel mit jedem Neuron zu verbinden, nutzt das CNN kleine, wiederverwendbare Filter, die über das ganze Bild gleiten.

So entsteht ein Netz, das:

  • viel weniger Parameter hat,
  • verschiebungsinvariant ist,
  • räumliche Nachbarschaften erhält.

Die Kernidee: Faltung (Convolution)

Ein kleines Fenster (Filter) wandert über das Bild und reagiert auf bestimmte Muster.

Stellen Sie sich eine Lupe mit Schablone vor, die Sie über das Bild schieben. An jeder Position fragt sie:

„Wie gut passt mein Muster hier?"

Das Ergebnis ist eine neue Matrix – eine Aktivierungskarte (feature map). Helle Stellen zeigen: „hier passt das Muster", dunkle: „hier nicht".

So funktioniert es mathematisch

An jeder Position: Filterwerte elementweise mit dem Bildausschnitt multiplizieren und alles aufsummieren.

y = Σ (Filter × Bildausschnitt)

Anschließend wandert der Filter ein Pixel weiter (Stride = 1) – und das Spiel beginnt von vorn.

Ein 3×3-Filter (Kantenerkennung) gleitet über das Eingabebild.

Die blaue Markierung zeigt das aktuelle Sichtfenster des Filters. Helle Pixel rechts = starke Filterantwort.

Was ist ein Filter eigentlich?

Eine kleine Matrix mit Zahlen – jede Zahl ist ein Gewicht, das das Netz lernt.

Beispiel: Vertikale Kanten

−1 0 +1 −1 0 +1 −1 0 +1

Reagiert dort stark, wo links dunkel und rechts hell ist – also an einer vertikalen Kante.

Wichtig zu verstehen

  • Ein CNN hat viele Filter pro Schicht (z. B. 32 oder 64).
  • Jeder Filter spezialisiert sich auf ein eigenes Muster.
  • Die Filterwerte werden nicht von Hand programmiert – das Netz lernt sie selbst durch Training.
  • Der gleiche Filter wird über das ganze Bild verwendet → geteilte Gewichte (Parameter Sharing).

Zwei wichtige Stellschrauben

🚶 Stride – die Schrittweite

Wie weit springt der Filter zwischen zwei Positionen?

  • Stride 1: Filter wandert pixelweise – feines Ergebnis.
  • Stride 2: Filter überspringt jedes zweite Pixel – Ausgabe halbiert sich.

Größerer Stride = kleinere Aktivierungskarte = schnellere Berechnung, aber gröber.

🖼️ Padding – Rand auffüllen

Ohne Maßnahmen schrumpft das Bild bei jeder Faltung. Mit Padding legt man einen Rand aus Nullen um das Bild.

  • „valid": kein Padding – Ausgabe schrumpft.
  • „same": Padding so gewählt, dass die Ausgabegröße gleich der Eingabegröße bleibt.

Aktivierungsfunktion: ReLU

Damit das Netz nichtlineare Muster lernen kann.

Nach der Faltung wird jeder Wert durch eine Funktion gejagt. Die einfachste und gebräuchlichste:

ReLU(x) = max(0, x)

Im Klartext: negative Werte werden zu 0, positive bleiben unverändert.

Warum? Ohne diese Nichtlinearität ließe sich ein tiefes CNN mathematisch zu einer einzigen linearen Operation zusammenfassen – es könnte nichts Komplexes mehr lernen.

ReLU schneidet alles unter 0 ab.

Pooling – das Bild verkleinern

Damit das Netz nicht in Pixeln ertrinkt.

Nach Faltung + ReLU folgt meist ein Pooling-Layer. Er fasst kleine Bereiche zusammen, z. B. 2×2-Blöcke.

Max Pooling

Aus jedem 2×2-Block wird nur der größte Wert übernommen.

Effekt:

  • Bild wird auf die Hälfte verkleinert.
  • Auffällige Aktivierungen bleiben erhalten.
  • Das Netz wird robuster gegen kleine Verschiebungen.
Aus jedem 2×2-Block bleibt das Maximum.

Die Architektur eines CNN

Faltung → ReLU → Pooling – mehrfach hintereinander, dann „flachgeklopft" und klassifiziert.

Bild28×28×1
→
Conv3×3, 32 Filter
→
Pool2×2 max
→
Conv3×3, 64 Filter
→
Pool2×2 max
→
Flatten + FC128 Neuronen
→
Softmax10 Klassen

Tiefer im Netz: räumlich kleiner, aber kanal-tiefer – die Information wird zunehmend „verdichtet" und abstrahiert.

Was lernen die einzelnen Schichten?

CNNs lernen Bilder hierarchisch – wie ein Kind, das zeichnen lernt.

1. Frühe Schichten Kanten, Linien, Farbverläufe. Wie die ersten Striche eines Bleistifts.
2. Mittlere Schichten Ecken, Texturen, einfache Formen. Aus Strichen werden Kreise und Quadrate.
3. Tiefe Schichten Komplexe Objektteile: Augen, Räder, Buchstaben. Aus Formen werden Gesichter und Autos.

Didaktischer Hinweis Schon Schüler:innen ohne Mathematikkenntnisse verstehen diese Hierarchie schnell – Visualisierungen gelernter Filter (z. B. von Olah/Distill) sind hier sehr eindrücklich.

Vom Bild zur Entscheidung

Flatten

Nach den Faltungs- und Pooling-Schichten wird die 3D-Aktivierung in einen langen Vektor „ausgerollt".

Fully Connected Layer

Dieser Vektor wandert durch eine oder zwei klassische, vollständig verbundene Schichten – sie kombinieren die gelernten Merkmale zu einer Gesamtbeurteilung.

Softmax

Die Ausgabe wird in Wahrscheinlichkeiten umgewandelt, die sich zu 100 % addieren.

Beispiel-Ausgabe

🐈 Katze: 87 %
🐕 Hund:   9 %
🐰 Hase:   3 %
🦊 Fuchs:   1 %

Das Netz entscheidet sich für die Klasse mit der höchsten Wahrscheinlichkeit – aber liefert immer auch ein Maß für seine Unsicherheit.

Wie lernt das Netz die Filter?

Drei Begriffe genügen für ein erstes Verständnis.

1. Trainingsdaten

Tausende Bilder mit bekannter Antwort („Das ist eine Katze"). Diese Paare sind das Lehrmaterial.

2. Verlustfunktion

Misst, wie weit die Vorhersage daneben liegt. Je größer der Fehler, desto stärker das Korrektursignal.

3. Backpropagation

Der Fehler wird rückwärts durchs Netz gerechnet. Jeder Filterwert wird ein winziges Stück in die richtige Richtung verschoben.

Dieser Zyklus läuft Millionen Mal. Am Anfang sind die Filter zufällig, am Ende erkennen sie verlässlich Kanten, Texturen, Objekte – ohne dass jemand das Aussehen einer Katze in Code formuliert hat.

Klassisches Beispiel: MNIST

70.000 handgeschriebene Ziffern – das „Hello World" der Bilderkennung.

Mit einem kleinen CNN (zwei Faltungsschichten, ~ 50.000 Parameter) erreicht man auf MNIST über 99 % Trefferquote – auf einem Laptop in wenigen Minuten.

Im Unterricht eignet sich MNIST hervorragend, weil:

  • Schüler:innen die Eingabe (eine Ziffer) sofort verstehen,
  • Fehler greifbar sind („das Netz hält meine 7 für eine 1"),
  • der Datensatz frei und klein ist.

Grenzen, Risiken und Verantwortung

Was Schüler:innen mitnehmen sollten – jenseits der Technik.

⚠️ Bias in den Daten

Wenn 90 % der Trainingsbilder helle Hauttöne zeigen, erkennt das Netz dunkle schlechter. Trainingsdaten = Weltbild des Netzes.

🎭 Adversarial Attacks

Winzige, für Menschen unsichtbare Pixeländerungen können das Netz dazu bringen, eine Schildkröte als Gewehr zu erkennen.

🔒 Datenschutz

Gesichtserkennung in öffentlichen Räumen wirft erhebliche rechtliche und ethische Fragen auf (DSGVO, KI-Verordnung).

🌍 Energie

Große Modelle verbrauchen erhebliche Mengen Strom – Nachhaltigkeit ist eine reale Designfrage.

🤖 Erklärbarkeit

CNNs sind Black Boxes. Warum eine konkrete Entscheidung fiel, ist oft schwer nachvollziehbar – kritisch in Medizin oder Justiz.

📦 Generalisierung

Ein auf Studio-Fotos trainiertes Netz versagt oft bei Schnappschüssen mit anderem Licht oder Hintergrund.

Ideen für den Unterricht

🎨 Filter per Hand

Auf Karopapier ein 5×5-Bild zeichnen, einen 3×3-Filter daraufschreiben, von Hand falten. Macht Faltung physisch erlebbar.

📷 Eigenes Mini-CNN

Mit Teachable Machine lassen Schüler:innen ein Netz auf eigene Geste, Farbe oder Objekt trainieren – in 10 Minuten.

🔍 Bias-Experiment

Trainieren mit absichtlich verzerrten Daten (z. B. nur eine Stiftfarbe). Klasse soll vorhersagen, was das Netz danach falsch macht.

⚖️ Ethik-Debatte

Pro/Contra: „Soll Gesichtserkennung in Bahnhöfen erlaubt sein?" – Sachargumente nach Datenschutz, Sicherheit, Bias.

🧪 CNN Explainer

Im Browser Schicht für Schicht durchklicken. Schüler:innen schreiben auf, was sie in jeder Schicht sehen.

🧮 Rechen-Aufgabe

Wie viele Parameter hat eine Conv-Schicht mit 16 Filtern, 3×3, 3 Eingangs­kanälen? (Lösung: 16·3·3·3 + 16 = 448)

Zusammenfassung in einem Bild

Drei Ideen tragen das ganze Konzept.

1. Faltung

Kleine Filter gleiten über das Bild und reagieren auf bestimmte Muster.

2. Hierarchie

Erst Kanten, dann Formen, dann Objekte – Schicht für Schicht abstrakter.

3. Lernen statt Programmieren

Niemand sagt dem Netz, wie eine Katze aussieht. Es findet die Filter selbst – durch viele Beispiele und Backpropagation.

Wer diese drei Ideen im Kopf hat, versteht 90 % aller Bilderkennungs-KI von heute.
