# 3.4 Brain-Behavior Correlation
To validate our RSFC patterns performed in Section 4, we assessed whether individual differences in RSFC could predict performance on behavioral tasks that specifically test the auditory 'what' and 'where' pathways. This approach links the network architecture observed during rest to cognitive function during task engagement, contributing validity for the supramodal organization hypothesis. 
## 3.4.1 Behavioral Subject Subsample
For the connectome-based predictive modeling, we used behavioral data of N = 371 participants from the HCP S1200 release. While the full resting-state cohort counts $N=812$ participants, restricting the behavioral analyses to the smaller subset guarantees complete data across all evaluated tasks.
## 3.4.2 Behavioral fMRI Tasks
Three fMRI tasks were selected to evaluate the auditory dual-stream framework, defined in our study. The tasks were selected to enable a functional dissociation between semantic processing 'what', auditory-spatial decoding 'where', and low-level acoustic filtering, while acknowledging the limitations of the HCP task set.
### Language Task (Story Comprehension)
In the story condition of the HCP Language Task, participants listened to short auditory stories adapted from Aesop's fables, followed by a two-alternative forced-choice (2-AFC) question testing the semantic content of the stories ([[Binder (2011)]], [[Barch et al. (2013)]]). Two performance measures were extracted: **Story Accuracy** measures the proportion of correct responses, and since the vocabulary of the stories is simple, we observe a ceiling effect in which the sustained attention is measured rather than semantic access. However, **Story Median Reaction Time** captures the speed of semantic retrieval and therefore is used as the primary measurement for ventral 'what'-stream efficiency. 
### Working Memory Task (2-Back Place)
The HCP Working Memory Task employs a visual N-Back design in which participants monitor sequential images and respond whether the current image matches the one presented two trials prior (Barch et al., 2013). The *place* subcondition, in which stimuli consisted of landscape and scene photographs, was extracted as a proxy for visuo-spatial working memory ([[Barch et al. (2013)]]).

This paradigm was selected as the closest available test of supramodal spatial processing capacity linked to the FEF-anchored dorsal "where" stream. A critical methodological constraint must be acknowledged: because the HCP dataset contains no auditory spatial N-Back task, this visual paradigm constitutes a cross-modal probe of the supramodal hypothesis. Participants may resolve the task via semantic object recognition strategies rather than spatial navigation, which may reduce sensitivity to purely dorsal network effects. The degree to which this limitation affects interpretability is discussed in Section 5.7.

### Words-in-Noise (NIH Toolbox Noise Comparison)

The NIH Toolbox Words-in-Noise test presents spoken English words masked by continuous speech-like background noise at an adaptive signal-to-noise ratio ([[Dikmen et al. (2014)]]). Responses are given by selecting one of four pictures. This test was included as a control paradigm indexing low-level acoustic signal filtering rather than high-level semantic processing.

By contrasting connectivity predictors for language comprehension versus acoustic noise filtering, it is possible to determine whether the prefrontal semantic controller (IFJa) subserves all auditory challenges uniformly, or whether acoustic separation operates on a lower, parieto-opercular processing level prior to prefrontal semantic engagement.

## 3.4.3 Connectivity-Based Behavioral Prediction

Brain-behavior relationships were assessed using a cross-validated linear regression framework as implemented in the BrainRest toolbox ([[Soyuhos, O., & Baldauf, D. (2023)]]). For each behavioral measure, the resting-state functional connectivity profile across the predefined ROI network served as the multivariate predictor. The connectivity values were derived from partial correlation matrices computed across the N = 371 subsample (`fMRI_partialcorr_371subjs`), reflecting direct functional coupling between ROIs with shared variance removed. The prediction model itself was fitted using linear correlation between the connectivity predictor matrix and the behavioural outcome variable.

Separate models were computed for the full network (all ROIs), the ventral target subset, and the dorsal target subset, enabling stream-specific predictions to be tested independently. For comparison, analyses were additionally run on full correlation matrices computed over both the N = 371 subsample and the full N = 812 resting-state sample.

Model performance was evaluated using K-fold cross-validation (K = 371, leave-one-out, as the primary analysis; K = 10 for comparison), yielding a cross-validated R value as the index of predictive accuracy. A significance threshold of p < 0.05 was applied throughout. The leave-one-out approach was prioritized as it maximizes the use of available data while providing a stringent within-sample validity test.

## Zusammenfassung der Methodik-Sektion

- **Language Task (Story):** Misst den "What"-Stream. RT operationalisiert die semantische Zugriffsgeschwindigkeit; Acc ist durch Exekutivfunktionen überlagert.
    
- **WM Task (2-Back Place):** Dient als supramodaler Proxy für den räumlichen "Where"-Stream, bringt jedoch die Limitation visueller Objekterkennungsstrategien mit sich.
    
- **Noise Comp Task:** Dient als sensorisches Kontrollmaß, um präfrontale Bedeutungsverarbeitung ("What") von rein akustischer Signalfilterung ("Cocktail-Party-Effekt") abzugrenzen.
    
- **Akademischer Ton:** Die Begründungen sind funktional formuliert und benennen die Schwächen (wie die Modalitäts-Diskrepanz beim Place-Task) proaktiv, was deine wissenschaftliche Eigenständigkeit unterstreicht.
