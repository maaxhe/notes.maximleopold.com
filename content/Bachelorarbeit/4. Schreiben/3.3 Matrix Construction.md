# 3.3 Matrix Construction

## 1. The BrainRest Toolbox
The Toolbox we are using is the BainRest Toolbox from the Baldauf Research Group performing two tasks for this analysis: 
1. Functional Connectivity Analysis


--------------------------------------------------------------------------------------------------------------------------------------------
                                                                   REQUIREMENTS
--------------------------------------------------------------------------------------------------------------------------------------------
- Please use MATLAB R2022a or later. 

- Include the BrainRest_data which contains the connectivity matrices for rfMRI and rMEG (of 55, 371, and 812 subjects from the Human Connectome Project).

NOTE: Please select the directories from the interface before running the app for the first time. Ensure the lamps are green before pressing the run button.

--------------------------------------------------------------------------------------------------------------------------------------------
                                                    rMEG / rfMRI FUNCTIONAL CONNECTIVITY
--------------------------------------------------------------------------------------------------------------------------------------------
- When contrast is FALSE: 
  Significance test for functional connectivity analyses are applied against the mean connectivity values of the whole brain for the selected frequency range (one-tailed Wilcoxon signed-rank test; FDR-corrected).

- When contrast is TRUE: 
  Tests whether each parcel in Glasser et al. (2016) has higher connectivity with 'Seed 1' or 'Seed 2' (two-tailed Wilcoxon signed-rank test; FDR-corrected).
       Red Areas: Predominant connectivity with 'Seed 1'.
       Blue Areas: Predominant connectivity with 'Seed 2' 

--------------------------------------------------------------------------------------------------------------------------------------------
                                                              rMEG FREQUENCY BANDS
--------------------------------------------------------------------------------------------------------------------------------------------
- Frequencies of Interest:
  Delta:   1-4 Hz    (Smoothing boxes: 1)
  Theta:   4-8 Hz    (Smoothing boxes: 1)
  Alpha:   8-13 Hz   (Smoothing boxes: 1)
  Beta:   13-30 Hz   (Smoothing boxes: 2)
  Gamma:  30-100 Hz  (Smoothing boxes: 10)

--------------------------------------------------------------------------------------------------------------------------------------------
                                                          rMEG DIRECTIONALITY ANALYSIS
--------------------------------------------------------------------------------------------------------------------------------------------
- In addition to the bidirectional coupling, the toolbox tests whether one unidirectional connectivity is statistically more robust than the other direction (two-tailed Wilcoxon signed-rank test; FDR-corrected).

  Magenta-colored regions: Predictive of spontaneous activity in a 'Seed'.
  Green-colored areas: 'Seed' is predictive of their activity.

--------------------------------------------------------------------------------------------------------------------------------------------
                                                                   REFERENCES
--------------------------------------------------------------------------------------------------------------------------------------------
